## How to work through this document

**Read this whole section before touching anything.**

0. **THE ROOT HTML FILES ARE BUILD OUTPUTS. NEVER HAND-EDIT THEM.**
   `index.html`, `about.html`, `services.html`, `careers.html`, `contact.html`, `testimonials.html`, `projects.html` are compiled from `pages-src/*.html` + `partials/*.html` by `build/inject-partials.js`. Every `projects/*.html` detail page is generated by `build/generate-projects.js` from `partials/project-detail.template.html` + `data/projects.json`.
   Edit only: `pages-src/`, `partials/`, `src/styles/`, `data/`, `js/`. Then rebuild:
   ```bash
   node build/inject-partials.js && npm run build:pages
   ```
   If `build:pages` fails on a missing `images/manifest.json`, run `npm run build:images` first — this requires the raw image sources, which exist on Ravi's machine but are not committed. **If the manifest cannot be produced, stop and report rather than regenerating pages with empty data** (a compile without the manifest silently empties the project-data island in `projects.html`).

1. **Verify before you change.** Every task is CHECK → CHANGE → VERIFY. Run the CHECK first. If what you find does not match this document, **stop and report the difference instead of proceeding.** The code is the truth.

2. **Never rewrite a file wholesale.** Targeted edits only. If a file needs extensive change, show the diff and ask before applying.

3. **`CLAUDE.md` is append-only.** It exists at the repo root (v1.1 content). Append the Phase 5 block under a new heading; do not replace, reorder or rewrite what is there.

4. **Work in phases and report between them.** Complete a phase, report what changed, wait for a go-ahead.

5. **Do not hand-translate token values.** Copy CSS blocks from this document verbatim — except where Phase 2 explicitly says the draft block must NOT be pasted verbatim because of naming collisions.

6. **If a task conflicts with something that looks deliberate, ask.** A deliberate decision that contradicts the spec is a spec problem, not a code problem.
