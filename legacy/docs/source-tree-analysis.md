## Entry Points

| Entry | Path | Description |
|---|---|---|
| Website root | `index.html` | Browser lands here; initiates AJAX shell |
| Contact form | `php/contact.php` | Only server-side entry point; POST only |
| Apache config | `.htaccess` | HTTP→HTTPS redirect |

---

## Critical Folders

| Folder | Criticality | Notes |
|---|---|---|
| `css/` | High | Changing load order breaks styles |
| `js/` | High | `core.js` must load after `plugins.js` |
| `php/` | Medium | Only `contact.php` — single backend file |
| `images/folio/` | High | Portfolio thumbnails + project images; naming matches HTML `<img src>` paths |
| `fonts/` | Medium | All font formats needed for cross-browser support |
| `docs/` | Low (site) | BMad AI context only — not served to users |
| `_bmad/` | Low (site) | BMad tooling only — not served to users |
