## Getting Started

**To browse the site locally:**
```bash
cd g:/proarc
python -m http.server 8000
# Open http://localhost:8000
```

**To add a new project:**
1. Copy an existing project page: `cp woodlem.html newproject.html`
2. Add thumbnail: `images/folio/thumbs/newproject.jpg`
3. Add project photos: `images/folio/projects/newproject1.jpg` … `newproject3.jpg`
4. Add `<div class="gallery-item [category]">` block to `portfolio.html`
5. See [Development Guide](./development-guide.md) for full step-by-step

**To deploy changes:**
Upload changed files via FTP to the Apache hosting server. See [Development Guide → Deployment](./development-guide.md#deployment).

**To plan new features with BMad:**
